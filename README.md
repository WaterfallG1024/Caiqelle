# Caiqelle

Windows 11 向けの高速画面キャプチャ・リワインド・情報整理ユーティリティです。  
WinUI 3 (Windows App SDK) と .NET 10 で構築されており、タスクトレイ常駐による軽量な動作と Fluent 2 準拠の UI を備えています。

## 主な機能

### キャプチャ・編集
- **範囲選択キャプチャ (`C`)**: 画面の任意の範囲を選択し、図形・矢印・ペン・連番スタンプなどの描画ツールで注釈を加えて保存またはコピーできます。
- **ウィンドウキャプチャ (`W`)**: カーソル下のウィンドウを自動ハイライトし、ワンクリックでキャプチャできます。
- **全画面キャプチャ (`F`)**: 仮想デスクトップ全体を即座にキャプチャします。
- **自動クリップボードコピー**: ON にすると、上記 3 つの基本キャプチャ時に編集・保存画面を開かず直接クリップボードへコピーします。
- **ピン留め (`P`) / ライブピン留め (`L`)**: 指定領域を最前面のフローティングウィンドウとして画面上に固定できます。ライブピン留めは指定領域をリアルタイムに追従表示します。
- **テキスト抽出 / OCR (`E`)**: 選択範囲内の文字を認識し、クリップボードへコピーします。

### フォルダ振り分け保存
- 保存先フォルダと 1 文字のショートカットキー（最大 44 件）を紐付け、キャプチャ後にキーを押すだけで素早く指定フォルダへ保存できます。

### リワインド（バックグラウンド録画）
- 直近の画面操作を指定秒数（3秒〜20分）・指定画質（720p〜4K）でメモリ上にリングバッファ記録し、後から任意のフレームを画像として切り出せます。
- `Shift + CapsLock` による一時停止/再開に対応しています。
- 省メモリ差分録画（16分割・Beta）に対応しています。

### Sticky Text（付箋メモ）
- 画面上に軽量な付箋メモを作成・一覧管理できます。
- 画面共有や録画に映り込まないプライベートモード、テキスト・書式・配置の自動保存・復元に対応しています。

### Action（フォーム自動認識・自動入力 / Beta）
- 画面上のフォーム項目を OCR で認識し、確認ピル UI から登録済みの値を自動入力します。
- 入力値は Windows DPAPI（アプリ固有エントロピー付き）で暗号化して保存されます。

## ホットキー一覧

| キー | 動作 |
|---|---|
| `PrtScn` / `Win + Shift + S` | キャプチャランチャーを表示 |
| `Ctrl + PrtScn` | クイックアクセス画面を表示 |
| `Shift + PrtScn` | リワインド再生画面を開く |
| `Shift + CapsLock` | リワインドの一時停止 / 再開 |
| `Esc` | ウィンドウを閉じる / キャンセル |

## 動作環境

- OS: Windows 10 (1809 以降) / Windows 11
- 対応アーキテクチャ: x64

## インストールとアップデート

[Releases](https://github.com/WaterfallG1024/Caiqelle/releases) ページからインストーラーをダウンロードして実行してください。  
Velopack によるバックグラウンド自動アップデートに対応しています。

## 開発・ビルド方法

### 必要環境
- .NET 10 SDK
- Windows App SDK 2.6.5

### ビルドコマンド

```powershell
dotnet build -c Release -p:Platform=x64
```
